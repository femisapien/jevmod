A score for every message. You decide what happens.

Rates every message in your Discord server for spam, scams, harassment and four more. Flags to a private channel. Deletes only if you turn that on.

The live demo is closed right now. The example buttons still show what jevmod answered for them on 2026-09-18; run jevmod check with your own key for a live one.

Your text goes to this demo server and to TypeSafe's API, and stays in the demo log with a hashed IP. Do not paste anything private.

It flags. It does not act until you say so.

The bot creates a private #jevmod-log channel. A flagged message appears there with its category, its probability and the message. Nothing is posted when the bot cannot create or reach that channel, and nothing is judged at all while the server is over its monthly quota or the model is unreachable. Members see nothing.

Nine questions. Seven asked by default.

Every category you have on gets its own probability from 0 to 1. Over the line for that category, the message is flagged. Off-topic and written by a model are off until you turn them on, so a new server gets seven numbers. A message the local filters settle is never sent to the model and gets no numbers at all.

Spam
Advertising pushed at the community, referral and invite links, repeated offers, mass mentions.
Scam
Fake giveaways, look-alike domains, staff impersonation, anything after your members' money, accounts or passwords.
Harassment
Insults, slurs, threats and abuse aimed at a person or a group, in any language.
Adult content
Explicit sexual content or graphic gore in a general audience channel.
Off-topic
A message with nothing to do with the channel's topic. Off by default; /mod set offtopic flag turns it on.
Self-harm
A member saying they want to die, disappear or hurt themselves. It flags so a moderator can reach out.
Doxxing
A home address, phone number, real name or workplace of a real person, or asking others to find them.
Minors
Sexual comments about someone under 18, or an adult building private trust with a child.
Written by a model (experimental)
A message that reads as assistant output rather than someone typing. Off by default; /mod set ai_generated flag turns it on. On our test set it separates model output from real chat almost perfectly, AUROC 0.971. A real channel is not that test set: at a realistic 2 in 100 rate of pasted model text, we project that only 19 to 37 of every 100 flags would be right, so most flags would be wrong. It also flags members who write in an encyclopedic register. An experimental category can only flag: jevmod refuses to set it to delete or time out, and the reactions never move its line.

Add up to five rules in your own words: No politics. News about the game is fine.

Three commands cover most days.

/mod set scam delete 0.7 moves scam from flagging to deleting, with the line at 0.7.

/mod rule adds a rule in plain language.

React ❌ on a log entry when the bot was wrong and the line for that category moves up 0.03. ✅ moves it down 0.02.

What it can do

Flag is the default. Delete needs the Manage Messages permission. Time out, 10 minutes, needs Moderate Members. It cannot ban anyone.

Roles you mark as trusted are never judged, and neither is anyone who can Manage Messages. A member whose message is removed gets a direct message saying an automated system did it and how to appeal to your moderators.

Measured on 2,531 public messages with human labels.

The four numbers below come from 1,680 of those messages, OpenAI's moderation set. The other 851 are 351 Civil Comments and 500 YouTube spam comments.

AUROC measures how well the scores rank messages: 1.0 is a perfect ranking, 0.5 a coin flip. It says nothing about how much gets caught, because that depends on the line, and the lines jevmod ships with are high. On the YouTube spam set it catches 36 of every 100. Moving a line down with /mod set, or with the ❌ and ✅ reactions, catches more and costs more false positives.

On OpenAI's moderation set jevmod has the best AUROC in every category it was compared on, against Llama Guard 3, ShieldGemma and toxic-bert. On the any-violation row it ties with ShieldGemma 2B, both at 0.939. It loses on Civil Comments to toxic-bert, which was trained on that set.

Five categories have numbers here: harassment, sexual content, self-harm, minors and spam. Scam, doxxing and off-topic have no labelled public set in this benchmark, so they were not measured. Written by a model was measured separately.

The full table, with cost and latency per system, is on the developers page.

What it will never do.

Ban anyone.
It has no ban permission and no ban command.
Delete while unsure.
If the model does not answer, the bot does nothing with that batch. Nothing is removed on a guess.
Store your messages.
The hosted bot runs with JEVMOD_KEEP_TEXT_CHARS set to 0, so it stores no message text. A copy you run yourself keeps the first 300 characters of a flagged message until you set that variable to 0. Messages that pass are not stored at all.
Send who wrote it.
Only the text and the channel topic go to the model. Names and ids stay in your server.

/mod upgrade is the command that starts a subscription. On a Free server it opens Stripe Checkout; once the server is on Pro the same command opens the billing portal instead. Today that command answers that there is nothing to pay, because no Stripe keys are set on the server.

Judged means sent to the model. Messages under eight letters without a link, and messages from trusted authors, are settled locally and do not count. Neither does a repeat of text the bot judged before with the same channel topic and the same categories on. That cache lives in the running bot's memory, holds an answer for 24 hours, and is empty again after a restart.

For each flagged message the hosted bot writes one row and keeps it 30 days: a timestamp, the server, a request id, the message id, the author id, the first 80 characters of the channel topic, the category, its probability, the action taken, and the probability of every category asked. The row has a text column too, and the hosted bot leaves it empty. The full list is on the privacy page. Messages that pass are not kept.

/mod forget deletes everything stored about your server, and so does kicking the bot. Neither one touches Stripe. Cancel a Pro subscription in the billing portal first, or it keeps charging.
