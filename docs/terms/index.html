The hosted bot

By default every category except offtopic is set to flag: the message is reported to your log channel and nothing else happens.

The offtopic category is off by default.

The bot deletes a message or times a member out only for a category or rule you have set to delete or timeout with /mod set or /mod rule.

A time out lasts 10 minutes.

The bot never bans anyone: its only actions are off, flag, delete and timeout.

Thresholds go from 0.50 to 0.99.

You can add up to 5 rules in your own words.

Decisions are probabilities from a machine-learning model compared with thresholds you set; there will be false positives and false negatives.

You are responsible for the actions you enable, for the rules you write, for telling your members that automated moderation is in use, and for complying with the law that applies to your community.

Plans and billing

Pro is not on sale at the moment. The hosted instance runs without Stripe keys, so /mod upgrade answers that this copy is self-hosted and there is nothing to pay. No plan can be bought and no card is charged today. The paragraphs about Pro below are the terms that apply if it opens.

The Free plan covers 5,000 judged messages per server per month.

The Pro plan costs $3.99 per server per month.

Pro covers 50,000 judged messages per server per month.

Judged means sent to the model: the counter grows only by messages the model receives, so messages skipped by the local filters or answered from the cache do not count.

When a server reaches its quota, judging pauses until the next calendar month and nothing is deleted while paused.

The bot posts one notice in the log channel the first time the quota is reached in a month, and /mod status shows the count at any time.

If it opens, Pro is a monthly subscription paid through Stripe Checkout, one price per server, started with /mod upgrade.

Once a subscription exists you can cancel it at any time from Stripe's billing portal, reached with the same /mod upgrade command.

When the subscription ends the server returns to the Free plan.

A period already paid is not refunded, except by writing to the operator through the contact below; refunds are handled by hand.

Availability

There is no service level agreement; jevmod is not the right tool if you need one.

If the model cannot be reached, the bot takes no action on that batch of messages and lets them through.

The self-harm category

The selfharm category exists to alert moderators so a person can reach out. It is not a medical or crisis service and must not be used as one.

It is flag-only by design in the defaults.
